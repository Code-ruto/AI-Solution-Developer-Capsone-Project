# SimBot

SimBot is an AI-powered simulation chatbot designed to provide interactive, voice-based conversations for simulation and training environments.

This project expands on an earlier chatbot prototype by integrating a local, open-source Large Language Model (LLM) as the conversation engine. The application uses user input, simulation scenarios, persona instructions, and conversation history to generate dynamic responses.

## Features

* AI-generated conversational responses
* Voice input and text-to-speech output
* Persona-based simulation conversations
* Desktop graphical user interface
* Local LLM inference
* Designed for Raspberry Pi 5 deployment

## Project Goals

The primary goal of this project is to explore the development and deployment of a locally running AI application. It focuses on LLM integration, prompt engineering, application architecture, voice interaction, testing, and edge AI deployment.

## Status

This project is currently under development as part of a capstone project. Features and implementation details may change as development progresses.
